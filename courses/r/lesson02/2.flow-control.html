R Flow Control

R Flow Control

  • In R, boolean variables can take only 2 values: TRUE and FALSE.
  • Comparison operators are used to compare two values.
Operator Description Example
> Greater than 5 > 6 returns FALSE
< Less than 5 < 6 returns TRUE
== Equal to 5 == 6 returns FALSE
!= Not equal to 5 != 6 returns TRUE
>= Greater than or equal to 5 >= 6 returns FALSE
<= Less than or equal to 5 <= 6 returns TRUE

  • Logical operators are used to compare the output of two comparisons. There are three types of logical operators in R.

  • AND operator &

  • OR operator |

  • NOT operator !

x <- 2
y <- 5
z <- 3
print((x >= y) | !(y < z))
[1] TRUE

Nested if ... else Statement

x <- 20
# check if x is positive
if (x > 0) {
  # check if x is even or odd
  if (x %% 2 == 0) {
    print("x is a positive even number")
  } else {
    print("x is a positive odd number")
  }
  # execute if x is not positive
} else {
  # check if x is even or odd
  if (x %% 2 == 0) {
    print("x is a negative even number")
  } else {
    print("x is a negative odd number")
  }
}
[1] "x is a positive even number"

R Function

  • In this tutorial, you will learn everything about functions in R programming; how to create them, why it is used and so on.

  • Functions are used to logically break our code into simpler parts which become easy to maintain and understand.

  • It’s pretty straightforward to create your own function in R programming.

User-Defined Functions

# no parameter and no return function
hello <- function() {
  print("Hello, R Programming!")
}
hello()
[1] "Hello, R Programming!"
# no return but with parameter function
hello <- function(name) {
  print(paste("Hello,", name))
}
hello(name = "Michael")
[1] "Hello, Michael"
# no return but with default parameter function
hello <- function(name = "R Programming") {
  print(paste("Hello", name))
}
hello()
hello(name = "Michael")
[1] "Hello R Programming"
[1] "Hello Michael"
# function with parameter and return
square <- function(x) {
  (return(x^2))
}
x <- 3
y <- square(x = x)
print(paste("x^2 =", y, "where x =", x))
[1] "x^2 = 9 where x = 3"
# R recursive function
f <- function(n) {
  if (n == 0) {
    p <- 1
  } else {
    p <- n * f(n - 1)
  }
  (return(p))
}
p <- f(n = 5)
print(p)
[1] 120
# The ellipsis ... parameter
greet <- function(..., greet_word = "Hello,") {
  names <- list(...)
  for (name in names) {
    print(paste(greet_word, name))
  }
}
greet("Michael", "Lucy", greet_word = "Hi,")
# The ... generally comes last but since other parameters have default values
[1] "Hi, Michael"
[1] "Hi, Lucy"

  • R Infix Operator

  • Most of the operators that we use in R are binary operators (having two operands). Hence, they are infix operators, used between the operands. Actually, these operators do a function call in the background.

  • For example, the expression a+b is actually calling the function `+`() with the arguments a and b, as `+`(a, b).

# R Infix Operator
a <- 2
b <- 3
c <- `+`(a, b)
d <- `-`(`*`(a, b), 5)
print(c)
print(d)
[1] 5
[1] 1

  • R User-Defined Infix Operator

  • It is possible to create user-defined infix operators in R. This is done by naming a function that starts and ends with %.

# R User-Defined Infix Operator
`%divisible%` <- function(x, y) {
  if (x %% y == 0) {
    (return(TRUE))
  } else {
    (return(FALSE))
  }
}
print(6 %divisible% 3)
print(6 %divisible% 5)
[1] TRUE
[1] FALSE

Statistical Distributions and Their Functions

In R, most distributions follow a standard naming convention:

  • dXXX() -> density
  • pXXX() -> cumulative distribution
  • qXXX() -> quantile
  • rXXX() -> random generation

Replace XXX with a distribution abbreviation (like norm, binom, pois, etc.)

Distribution Prefixes Used Description
Normal dnorm, pnorm, qnorm, rnorm Gaussian distribution
Binomial dbinom, pbinom, qbinom, rbinom Fixed number of trials
Poisson dpois, ppois, qpois, rpois Count data
Uniform dunif, punif, qunif, runif Equal probability
Exponential dexp, pexp, qexp, rexp Time between events
t-distribution dt, pt, qt, rt Student’s t-distribution
Chi-squared dchisq, pchisq, qchisq, rchisq Variance tests
F-distribution df, pf, qf, rf ANOVA and regression
Gamma dgamma, pgamma, qgamma, rgamma Skewed continuous data
Beta dbeta, pbeta, qbeta, rbeta Bounded [0,1] data
