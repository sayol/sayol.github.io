  • And then click on Download R for Windows
  • Click on base
  • Click on Download R 4.5.1 for Windows

  • Click on OK button
  • Click on Next button
  • Click on Next button

  • Just wait until the installation is finished
  • Click on Finish button

Installation via WinGet

  • Launch Windows PowerShell and execute
winget search "RProject"
  • Copy the id RProject.R and execute
winget install RProject.R
  • If R is not already installed on the system, winget will donwload and install automatically.
  • In case of already installed, the warning message is prompted as in the following screenshot.

Launch R Application

R comes with its R Graphical User Interface where you can 1. execute R script in console (R Console) 2. and develop R script in editor (R Editor)

Follow these steps to get started * In the Windows search box type Apps: R * And then click on the R Logo

  • This is how R console looks like
  • To open R script editor go to menu bar and click on File -> New script
  • Write your first R script:
print("Hello R Programming!")
  • Go to menu bar and click on File -> Save
  • Choose an appropriate location and name your file example.R
  • To run the saved R script go to menu bar and click on Editor -> Run all
  • The resulting output appears in the R Console
[1] "Hello R Programming!"

Add Installed R Directory to System Environment Variables Path

  • Search for Settings: Edit the system and open it
  • Select the Advanced tap and then click on Environment Variables
  • Under User variables for [User], select Path and click on edit
  • Click on New button and add the R executable directory (See the following steps how to get the directory)

Find the location of R executable files

  • To make sure that your have copy the correct location of the R executable directory, launch File Explorer by searching Apps: File Explorer
  • Select drive C: and then open a folder called Program Files
  • Scroll down to find the subdirectory R
  • After that find and open R-[version]. For instance, R-4.5.1
  • Open the bin (binary) subfolder
  • Finally open the x64 directory
  • Here where you can correctly copy the directory containing the R executable files
  • Note that you have to place the mouse cursor at the end of x64 in the box to copy the address

Configurate R with Jupyter Notebook in Visual Studio Code

  • First, assuming that you have already install Python (and added path to the system environment variables) and Jupyter

  • To verify the installation of Python and Jupyter, launch the Windows PowerShell and execute the following shell script

python --version

then

jupyter --version
  • If you have also configured correctly, you can launch R Console (R Terminal) in Windows PowerShell as
rterm

  • Follow the instruction from https://github.com/IRkernel/IRkernel

  • Download and install IRkernel with following script

install.packages("IRkernel")
  • There is probably a confirming panel to select the Secure CRAN mirrors, just leave selection the first one from the top and click OK
  • Then register the R kernel in the current R instalation by executing the following script
IRkernel::installspec()
  • If there is no warning or error message, it means you installed and registered successfully
  • To quit the R console, execute the script
q()

and then type

n

to confirm not to save

Launch the Jupyter Notebook

  • Assume you have installed and configured correctly without error, you can now launch the Jupyter Notebook by executing the Windows PowerShell script as follow
jupyter notebook
  • After an internet browser is launch after executing script from the previous step, click on New (at the top-right corner) and choose R
  • After another tap is opened, write R script in the Jupyter Notebook code cell
summary(c(1, 2, 3, 4, 5))
  • If you want to save the notebook just go to toolbar and choose File -> Save Notebook
  • To shutdown the Jupyter Notebook and R kernel safely, go to toolbar and choose Kernel -> Shut Down All Kernels…
  • Otherwise, come back to your Windows PowerShell and press CTRL+C on your keyboard

R and Jupyter Notebook in Visual Studio Code

  • Assuming that you have already installed Visual Studio Code
  • First, launch Visual Studio Code, click on the Extension icon then search for REditorSupport and install both R Syntax and R
  • Copy the script install.packages("languageserver")
  • Install the R Language Server support by executing R script
install.packages("languageserver")
  • Search for and install the Jupyter extensions pack Jupyter

Create New Jupyter Notebook File

  • Go to toolbar and choose File -> New File…
  • Choose Jupyter Notebook

Save Jupyter Notebook

  • Go to toolbar and choose File -> Save As…
  • At the top right corner, click on Select Kernel and the choose Jupyter Kernel… from the palette
  • Type some R script and execute
summary(c(1, 2, 3, 4, 5))
  • Note that to format the R code, you have to click on the R logo extension icon on the left side (by default) of the Visual Studio Code window.
  • To format a code cell, just place the mouse cursor in it and press ALT+SHIFT+F.

R Variables and Constants

  • As in another programming language, a variable changes its value when needed.
  • Variable in R is not need to be declare before use.
  • The data type (object type) in R is dynamic. It can be change from one another if needed.
  • To assign value to a variable, we use <- notation.
# Object type
x <- 2
y <- 3.4
z <- x + y
s <- "R Programming"
b <- TRUE
print(class(x))
print(class(y))
print(class(z))
print(class(s))
print(class(b))

R cat() Function

R programming also provides the cat() function to print variables. However, unlike print(), the cat() function is only used with basic types like logical, integer, character, etc.

# print using `cat()` function
cat("Hello\t")
cat("R\t")
cat("Programming\n")
word <- "User"
cat("Goodbye", word, sep = " ")
Hello   R   Programming
Goodbye User

R Numbers

Numbers in R can be divided into 3 different categories:

  • Numeric: It represents both whole and floating-point numbers. For example, 123, 32.43, etc.
  • Integer: It represents only whole numbers and is denoted by L. For example, 23L, 39L, etc.
  • Complex: It represents complex numbers with imaginary parts. The imaginary parts are denoted by i. For example, 2 + 3i, 5i, etc.
