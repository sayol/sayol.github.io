R Data Frame

The data.frame is one of the most fundamental and commonly used data structures in R, especially for tabular data.

It stores data in a table format, with columns (variables) that can be of different types (numeric, character, logical, etc.) and rows (observations).

Parameter Description Default
... Named vectors, lists, or columns to include in the data frame Required
row.names Character vector or numeric values to assign row names NULL (auto)
check.rows Logical: check rows for equal length (mostly for internal use) FALSE
check.names Logical: make variable names syntactically valid R names (e.g., no spaces) TRUE
stringsAsFactors Logical: convert character vectors to factors (deprecated in R \(\geq\) 4.0.0) default = FALSE in R \(\geq\) 4.0.0

This is an example of tabular data that is used in this tutorial.

name gender age degree job salary status
id0001 Michael Male 35 Doctor Programmer 850 Single
id0002 Lucy Female NA Master Designer 525 Single
id0003 Jane Female 27 Bachelor Teacher 500 Married
id0004 John Male 28 Master Engineer 1200 Single
id0005 Smith Male 32 Doctor Manager 970 Married

The following table shows common functions and their usages.

Operation Code Example
View first/last rows head(df) or tail(df)
View column names names(df) or colnames(df)
View structure str(df)
Access column df$name or df[["name"]]
Subset by rows & columns df[1:2, c("name", "age")]
Add a column df$senior <- df$age > 30
Filter rows subset(df, age > 27)

Creation

Basic syntax of R data frame is data.frame(colname = sequence).

df <- base::data.frame(
  "c1" = base::c(5, 4, 8),
  "c2" = base::c("E", "F", "B")
)
df
A data.frame: 3 × 2
c1 c2
<dbl> <chr>
5 E
4 F
8 B

We can specify the row labels by row.names = sequence.

df <- base::data.frame(
  c1 = base::c(5, 4, 8),
  c2 = base::c("E", "F", "B"),
  row.names = base::c("r1", "r2", "r3")
)
df
A data.frame: 3 × 2
c1 c2
<dbl> <chr>
r1 5 E
r2 4 F
r3 8 B

Cast the data type to numeric by as.numeric and to ordinal by factor(levels = sequence, ordered = TRUE).

df <- base::data.frame(
  c1 = base::as.numeric(x = c("5", "4", "8")),
  c2 = base::factor(
    x = base::c("E", "F", "B"),
    levels = base::c("F", "E", "D", "C", "B", "A"),
    ordered = TRUE
  ),
  row.names = base::c("r1", "r2", "r3")
)
df
A data.frame: 3 × 2
c1 c2
<dbl> <ord>
r1 5 E
r2 4 F
r3 8 B

A new row can be added to the end of the data frame by df[newrow, ] <- list. We use list rather than c because generic list can store different type of data while c cannot.

df <- base::data.frame(
  name = base::as.character(x = base::c("Michael", "Lucy", "Jane", "John")),
  gender = base::as.character(x = base::c("Male", "Female", "Female", "Male")),
  age = base::as.numeric(x = base::c(35, NA, 27, 28)),
  degree = base::factor(
    x = base::c("Doctor", "Master", "Bachelor", "Master"),
    levels = base::c("Bachelor", "Master", "Doctor"),
    ordered = TRUE
  ),
  job = base::as.character(x = base::c("Programmer", "Designer", "Teacher", "Engineer")), # nolint
  salary = base::as.numeric(x = base::c(850, 525, 500, 1200)),
  row.names = base::sprintf(fmt = "id%04d", 1:4)
)
# adding a new row
df["id0005", ] <- base::list("Smith", "Male", 32, "Doctor", "Manager", 970) # nolint
df

Subsetting

The subset() function in R is a convenient wrapper for subsetting data frames, matrices, or vectors using logical conditions. It’s cleaner and more readable than using square brackets [] for filtering.

subset(x, subset, select, drop = FALSE, ...)
Argument Description
x The object to subset (usually a data frame, but can be a matrix or vector).
subset A logical expression indicating which rows to keep. It’s evaluated within the context of x.
select Expression for selecting columns to keep. Can be column names, numbers, or formulas like -columnName to exclude.
drop Logical. If TRUE, single-column results will be simplified (e.g., to a vector). Default is FALSE.
... Additional arguments (usually unused for basic use).
