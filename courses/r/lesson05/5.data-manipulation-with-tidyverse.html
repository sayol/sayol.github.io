Installation

We can install only the dplyr package

# !install.packages("dplyr") # nolint

Inspired by the book: R for Data Science by Hadley Wickham, we can install a bundle of R packages tidyverse which include forcats, ggplot2, lubridate, purr, readr, stringr and tible.

Concerning about confliction between packages dplyr and stats, there are two common functions filter() and lag(). The warning message inform user that ones should use the namespace to refer to a specific package. For instance, if you want to use the filter() from dplyr package, we have to write dplr::filter() instead of filter().

ggplot2

ggplot2 is a data visualization package for the R programming language. It implements the Grammar of Graphics, allowing users to build plots with layers, mappings, and themes. As one of the core tidyverse packages, it’s widely used to create elegant and customizable visualizations.

dplyr

dplyr provides a grammar of data manipulation, offering consistent verbs like filter(), select(), mutate(), summarise(), and arrange(). It simplifies data transformation by making these operations fast, intuitive, and memory-efficient, with support for both in-memory and database backends :contentReferenceoaicite:1.

tidyr

tidyr helps you turn data into tidy format—where each variable forms a column and each observation forms a row. It provides functions for reshaping data, such as spreading, gathering, nesting, and unnesting, streamlining data cleaning and preparation.

readr

readr offers a fast and friendly way to import rectangular data (like CSV, TSV, and fixed-width files). It guesses column types automatically, parses files efficiently in C++, and provides helpful error messages when data doesn’t match expectations.

purrr

purrr enhances functional programming in R by providing a consistent and expressive suite of mapping functions. It allows users to replace many for‑loops with cleaner, more readable code that works seamlessly with tidyverse data structures.

tibble

tibble reimagines R’s data frames to be more user‑friendly: they never convert strings to factors, display only the first rows and relevant columns, and eagerly alert users to problems. Tibbles are lazy and surly—doing less automatically but warning you earlier.

stringr

stringr provides a consistent, simple API for string manipulation built on top of the ICU-based stringi library. It makes tasks like detecting, locating, extracting, replacing, and splitting strings straightforward and expressive.

forcats

forcats simplifies working with categorical variables (factors). It offers tools to reorder levels, collapse rare categories, and modify factor ordering, addressing common pain points when handling categorical data.

lubridate

lubridate makes it easier to work with dates and times by providing functions to parse, manipulate, and do arithmetic with date-time data. It simplifies dealing with time zones, durations, intervals, and periods, making date-time data more manageable and less error-prone.

get_mode <- function(x) {
  ux <- stats::na.omit(object = base::unique(x = x))
  ux[base::which.max(x = base::tabulate(bin = base::match(x = x, table = ux)))]
}
