R String

  • A string is a sequence of characters. For example, “Programming” is a string that includes characters: P, r, o, g, r, a, m, m, i, n, g.

  • In R, we represent strings using quotation marks (double quotes, ” ” or single quotes, ’ ’).

string <- "Hello, R."
print(string)
[1] "Hello, R."

R String Manipulation

  • Some functions available for string manipulation in R:
    • grep() - It is used for pattern matching and replacement.
    • nchar() - With the help of this function, we can count the characters.
    • paste() - We can concatenate n number of strings using the paste() function.
    • sprintf() - This function makes of the formatting commands that are styled after C.
    • substr() - It is the substrings of a character vector.
    • strsplit() - Split strings at some specified pattern into a vector of string
    • regex() - It represents a character vector where matches are sought.
    • gregexpr() - An extension of the base function, this function retrieves the matching substrings.
    • toupper() - Convert to upper case.
    • tolower() - Convert to lower case.
  • We present a few R functions and leave the remaining ones for the reader to find them out.

R Vector

In R, a vector is the most basic data structure. It is a sequence of elements that are all of the same type.

There are two main types:

  • Atomic vectors (homogeneous data type)

  • Lists (can contain mixed data types – technically also a type of vector, but treated separately)

Atomic Vectors

There are six basic types of atomic vectors:

  1. Logical (TRUE, FALSE)
  2. Integer (1L, 2L)
  3. Double/Numeric (1.5, 2.3)
  4. Character ("a", "R")
  5. Complex (2+3i)
  6. Raw (rarely used, for bytes)

To create an atomic vector, we mostly use the following functions and operators:

  1. c() - the combine function
  2. : - the colon operation
  3. seq() - the sequence function
  4. rep() - the repeat function

The combine function combines different types of numbers include integers and floating numbers. To make an homogeneous atomic vector, the data type is coerced to double/number rather than integer

R Factor

  • A Factor is a data structure that is used to work with categorizable datas.

  • Suppose a data field such as marital status may contain only values from single, married, separated, divorced, or widowed.

  • In such a case, we know the possible values beforehand and these predefined, distinct values are called levels of a factor.

degree <- factor(
  x = c("Doctor", "Bachelor", "Master", "Doctor"),
  levels = c("Bachelor", "Master", "Doctor")
)
print(degree)
[1] Doctor   Bachelor Master   Doctor  
Levels: Bachelor Master Doctor
degree[4] <- "Bachelor"
